

# Arch Linux Rice

My personal Arch Linux + Hyprland setup.

## Things

- **OS:** Arch Linux
- **WM:** Hyprland
- **Bar:** Waybar
- **Terminal:** Foot
- **Shell:** Fish
- **Launcher:** Rofi
- **Browser:** LibreWolf
- **File Manager:** Dolphin
- **Editor:** Neovim

## Colors

- Background: `#101010`
- Foreground: `#F4F4F4`
- Blue: `#0F62FE`
- Red: `#DA1E28`
- Green: `#42BE65`
- Yellow: `#F1C21B`
