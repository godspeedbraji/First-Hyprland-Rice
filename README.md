## Keybinds

| Shortcut | Action |
|---|---|
| `SUPER + RETURN` | Open Foot |
| `SUPER + E` | Open Dolphin |
| `SUPER + SPACE` | Open Rofi |
| `SUPER + SHIFT + RETURN` | Open LibreWolf |
| `SUPER + W` | Close active window |
| `SUPER + Q` | Toggle floating |
| `SUPER + CTRL + S` | Take selected-area screenshot and copy to clipboard (not sure that the clipboard works) |
| `SUPER + PRINT` | Take full-screen screenshot and save to Pictures |
